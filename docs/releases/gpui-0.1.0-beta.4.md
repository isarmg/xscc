# XSCC GPUI 0.1.0-beta.4

本轮桌面热修复针对管理连接出现 `management handshake timed out` 的问题：直接密钥协商完成后，Hello 和后续管理消息使用同一条加密发送路径，避免明文帧被对端作为密文解析后关闭连接。受管授权、实例绑定和远程会话权限继续使用现有协议。

| 平台 | 桌面候选产物 |
| --- | --- |
| Windows 11 x86_64 | 控制端 setup/便携包、被控端 setup/文件归档 |
| Linux x86_64 / Wayland | 控制端与前台被控端归档 |
| macOS 26 Apple Silicon | 控制端与前台被控端应用归档 |

Windows、Linux 和 macOS 包统一标为 `0.1.0-beta.4`。Android 使用独立的 `0.1.0-beta.3.3`（versionCode 4）预览 APK 版本；iOS/iPadOS 继续仅提供需要自行签名的控制端候选，不提供被控服务。移动端版本号不改变桌面包的身份。

升级 Windows 被控端时，先关闭界面，运行原卸载程序，再运行新 setup。原卸载约定保留受管安装身份、已保存绑定和配置，不需要解绑或重置实例密码。不要删除受管数据目录或更改其权限。文件归档不能替代系统服务安装。控制端便携包应在关闭旧程序后替换程序文件，保留自己的原有配置目录。

发布前须核对成功 CI 的源码 SHA、artifact SHA-256、包内 `build-info.json` 或对应构建记录及包文件校验清单，确保各平台产物来自同一修复提交。候选工作流本身不创建 Release；发布来源以最终 `release-provenance.json` 为准。旧 `beta.3` 二进制不会随源码更新自动修复。

Windows 和 macOS 产物仍未签名。编译、加密传输回归、安装器检查及本机身份保留核对不等于跨设备串流或端到端性能验收；实际图像、声音、输入、系统权限和移动设备操作仍须在对应物理设备上验证。
