# xscc 1.0.0

正式资产见 [xscc v1.0.0](https://github.com/isarmg/xscc/releases/tag/v1.0.0)。构建、运行与安装验收证据以该标签指向的精确源码和对应官方工作流为准。

## 变更

- 精确消费官方 xcsc 1.0.0；删除 --state 旧别名，服务、安装器和脚本统一 --config。
- 交互授权码使用公共隐藏输入；当前操作说明统一软件版本。
- 归档验证覆盖实际 TAR 写入器生成的目录，同时继续拒绝链接、越界路径与没有交付文件的目录。

公共客户端源固定为 `6fca4299f5c34a79db1c7bd4e889b418d2a58e2d`。软件补丁号独立于业务协议、持久状态与 FFI ABI。

业务协议源码固定为 `xscs@25c9ec6950c4f64592dbba87fc05d0ad200fdf56`；对应协议包与业务格式为 `1.0.0` / `v1`。公共发行工具固定为 `3441aa1e36861ae961371be3e0ce4636d649c6c1`。

## 验证与交付

各平台的编译、原生运行和安装生命周期由相应平台工作流验证。正式包的外部 SHA256 与包内完整清单绑定全部交付文件、运行依赖及原始许可证；公开版本的验证结果以对应 v1.0.0 Release 和最终源码工作流记录为准。
