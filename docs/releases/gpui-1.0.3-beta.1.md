# XSCC 1.0.3-beta.1 修复候选

- 修复被控端启动仍调用已被原生入口拒绝的旧硬件探测命令，统一使用现有的有时限 stdout 探测，在接受会话前刷新显卡能力。
- 恢复移动会话帧泵的连续调度，处理原生视频表面更新和会话统计。
- 修复远程输入状态修正时主动隐藏 Android 输入法的问题。
- 为电脑键盘补上左右滑动翻页，保留纵向滚动与按键点击，避免滑动时误输入。

本候选提供 Windows 控制端、被控端和 Android 安装包。已通过 65 项主机侧 GPUI 移动控件测试和 Java 输入桥接回归；这些结果不代表 Android 实机串流验收。当前没有 Android USB 调试连接，实际串流帧率与手机交互仍需确认。
