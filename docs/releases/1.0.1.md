# xscc 1.0.1

- 保留 Sunshine 应用默认字段和诊断信息，校验应用变更输入，并区分写入前冲突与无法确定是否生效的变更。
- 修正 VideoToolbox realtime 设置与 Sunshine 的对应语义。
- 正常关闭时等待并结束客户端拥有的执行任务。
- 修正严格 umask 下安装目录不可遍历的问题，完善 Linux、Windows 和 macOS 安装与维护说明。
- 公共客户端支撑升级至 `xcsc 1.0.1`，固定 revision `d3e9b8db84e4ead70ec0bf8a596dbad697f7db24`；业务协议继续使用 `xscs-protocol 1.0.0`。

## 安装包

Windows x64 MSI、Linux x86_64 DEB、macOS arm64 未签名 PKG，以及各平台二进制归档、manifest 和 SHA-256 校验和。软件和安装包版本为 `1.0.1`，配置、管理协议及持久状态格式不变。

安装、配置与更新步骤见[平台部署指南](../platform-setup.md)。
