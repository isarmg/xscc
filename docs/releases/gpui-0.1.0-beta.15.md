# XSCC GPUI 0.1.0-beta.15

客户端采用暖色底与青绿色主色，移动会话工具栏、浮动按键、键盘和错误状态使用统一主题。浅色辅助文字和选中开关对比度已修正；现有圆角、控件尺寸和操作布局保留。

PipeWire减少一次整帧拷贝；Quartz在校验锁和内存布局后借用IOSurface，减少分配与拷贝。格式/名称复用、无多余外层锁的视频队列、只读订阅发送和故障日志节流减少串流开销。保留安全桌面检查、参考帧处理、拥塞恢复和刷新请求。

受保护绑定存储减少重复解析与读取，恢复保留实际验证过的凭据；磁盘内容变化仍拒绝覆盖。启动存储错误保留原因，移动通道断开与超时区分。Android安装版本码为15，预览签名与应用身份保持原规则。

本版保留Windows GPU纹理编码及同格式RAM硬件回退。编译、范围测试和硬件能力探测不等于实机达到60FPS；最终源码的多平台构建、实际安装与性能结果需独立验收。完整取舍、未采用项与运行面见docs/review-2026-10-29.txt。
