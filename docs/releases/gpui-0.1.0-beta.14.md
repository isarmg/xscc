# XSCC GPUI 0.1.0-beta.14

Windows 被控端候选启用已有 GPU 纹理编码能力，按捕获显卡和运行时探测选择可用的 H.264/HEVC 编码器。支持时使用 DXGI 纹理编码，避免原 RAM 路径的 CPU 读回及颜色转换；仍有 GPU 复制和转换，不宣称零复制。

纹理互操作探测不再屏蔽独立可用的 RAM 硬件编码器。VRAM 编码器初始化失败时，保持已协商的 H.264/HEVC 格式、尺寸、质量、关键帧间隔及请求帧率尝试 RAM 硬件编码；没有可用的同格式编码器时明确报错。Linux/macOS 保留原 native-host 路径，控制端不因此启用 VRAM 解码。

本版包含 beta.13 的解码缓冲复用、同包最后可用帧转换、统一根锁、原生回归和来源校验。Android 安装版本码为 14，手机端新增性能结论仍需实体设备验收。

优化前后的 Windows 实测基准：beta.12 的会话提交中位数 28 FPS；beta.13 自动 HEVC 为 41 FPS，临时 H.264 对照为 30 FPS，已恢复自动。以上均为同一台电脑、45 秒持续变化场景的稳定窗口结果，不能代表 beta.14、其它硬件或物理显示刷新率。beta.14 的实际支持与帧率以该版构建及安装后的独立验证记录为准。
