# XSCC 1.0.3-beta.2 统一串流流水线候选

- FFmpeg/AMD 显存编码统一采用现有异步流水线，取消60FPS分界；输入保留、输出轮询、关键帧恢复和GPU退出清理使用同一路径。
- Windows原生被控端在所有帧率下使用现有高精度定时器，预检查计入帧预算；仅指针变化不再消耗图像帧时隙。
- Android硬件解码在所有帧率下按同一帧预算公式轮询输出，等待范围保持1–4ms，取消60FPS时固定等待4ms的分支。
- 保留目标FPS上限、码率上限及现有协议，不把低帧率目标强制提高到高帧率。

本候选同时包含上一候选的硬件探测、移动帧调度和键盘修复。帧调度与Android输出轮询的回归测试已在旧实现复现、在新实现通过；AMF关键帧CPU回归通过。实际Windows帧率与Android实机验收另行记录，不能仅据单元测试宣称已达到目标帧率。本轮不创建虚拟显示器。
