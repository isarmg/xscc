# XSCC GPUI 0.1.0-beta.13

本版减少 Windows/Linux/macOS FFmpeg 解码输出的逐帧分配，同一包中优先转换最后一张可用画面。解码器仍完整处理参考帧，GPU 回读和 CPU 到 GPU 的上传仍存在。

桌面、移动产品与核心测试统一使用根 Cargo.lock；合并保留此前两个产品全部依赖的版本、来源和校验和。新增真实平台的解码缓冲回归、PR 桌面编译、Linux DRM 可选路径检查和 vendor 来源校验。

被控端每秒记录一次采集、颜色转换和编码分发的数字汇总，便于定位低帧率；Android 安装版本码为 13。

验收边界：本版源码优化与 CI 不代表实机已达到 60 FPS。优化前本机回环的精确基准中，会话提交中位数为 28 FPS；诊断画面自身提交约 57.3 FPS。Android 实机测试仍需安装对应新包后单独验收。完整取舍与变更面见 docs/review-2026-10-28.txt。
