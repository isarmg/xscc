# XSCC GPUI 0.1.0-beta.5

本版更新桌面会话布局、远程光标、受管连接和移动端管理热路径。

- 桌面会话默认将空间用于远程画面，设备侧栏可展开；屏幕、目标帧率、统计、全屏和断开操作集中在画面外的独立工具栏，不覆盖远端窗口按钮。统计支持关闭、简洁和详细，区分接收、解码和 UI 提交帧率。
- 视频更新复用独立缓存菜单；后台状态轮询不再禁用管理按钮，相同状态不重复刷新界面。晚到的旧轮询结果不能覆盖新操作结果。绑定密码仅在绑定成功后清除。
- 候选地址没有响应时，每隔 250 毫秒启动下一尝试；明确失败时立即继续，共享 18 秒连接预算。只有完成加密握手、双向管理证明和最新授权检查的连接才会胜出，其余尝试释放连接。
- 桌面 GPUI 会话接通远程光标形状、热点与位置，按显示器坐标和画面缩放绘制。光标形状使用有界缓存，不复制每个视频帧；未知形状回退到本机光标。
- 质量遥测在独立的最新值槽位合并，避免反复更新挤掉错误和权限事件；切换显示器时清除旧显示器指标。
- 移动端每次输入检查最新授权策略，在锁内借用数据，避免反复复制整个设备策略和密钥；状态处理移出渲染函数，图像上传仍由每个显示帧的单次预约合并，不随解码唤醒重复上传。后台状态没有变化时不重复通知界面。
- 移动端会话按钮采用可辨识的选中和禁用样式，目标帧率可选 30、60、90、120。目标值不保证设备实际输出同等帧率。绑定前复用服务地址校验，私网 HTTP 继续可用；绑定失败保留密码。
- 桌面按钮、设备卡片和输入框加入键盘焦点顺序。远程画面取得焦点后，Tab 和常用组合键仍按原输入路径发送远端。

Windows、Linux、macOS 使用 `0.1.0-beta.5`。Android 管理 APK 使用相同版本名和 versionCode 5，沿用固定预览签名，可覆盖安装先前的固定签名预览版。iOS/iPadOS 为需要自行签名的控制端候选。

发布收集器要求同一源码提交的五个平台候选全部成功，并检查制品来源和摘要。自动构建和单元测试不替代物理设备上的图形、输入、声音、显示扫描延迟和移动端生命周期验收。

本版没有声称接通 YUV/GPU 零拷贝解码呈现，也没有更改 GPU 交换链、采集编码流水线、远程剪贴板或移动端后台权限。保留现有认证与授权边界，产品入口继续为 GPUI。

光标形状缓存最多保留 128 个形状、16MiB 像素。已淘汰的形状再次仅以编号选择时，当前协议不会补发像素，界面恢复本机指针；远程光标呈现本轮只在桌面控制端接入。
