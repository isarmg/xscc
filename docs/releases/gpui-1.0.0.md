# XSCC 1.0.0

- 发布 Windows 11 x86_64、Linux x86_64、macOS 26 Apple Silicon 控制端和被控端，以及 Android ARM64、iOS/iPadOS 26 ARM64 控制端。
- 统一原生 GPUI 界面和 Maple 字体，精简顶部菜单，显示器、分辨率、刷新率、码率与虚拟屏数量独立调整。
- 移动端输入框支持系统选择和长按粘贴，改善菜单点击反馈、解绑确认及全屏黑边；iOS 会话按屏幕能力请求高刷。
- Windows 高刷临时虚拟屏会话支持临时主屏呈现，断连、撤销和程序退出恢复原主屏；启动时清理残留临时屏配置。
- Android 保留原包名及签名，版本号 1.0.0、versionCode 10000，可覆盖此前预览版并保留绑定。

所有发布包来自同一提交，并通过对应原生构建、回归测试及完整性校验。Windows/macOS 包未作发行签名，iOS IPA 需自行签名。

虚拟屏高刷已有本机原生对照数据：120Hz 临时主屏下约 119.5 次提交/秒、117.7 次独立捕获/秒；新集成版本尚未完成本机安装验收，不能据此宣称 UFO、Android 端到端帧率或异响已彻底解决。各端音频、硬件键盘和剪贴板能力以随包构建说明为准。

本 Release 为 XSCC 客户端及桌面被控端，不包含独立 XSCS 服务端。
