# xscc 1.0.3

## 本次变更

- Windows 轮转日志查询接入公共支撑库的 reader gate，在捕获轮转日志快照期间协调读写，避免轮转竞争遗漏记录；解析在释放 gate 后进行。
- 现有目录访问策略保持不变。已有查询过滤与 tail/follow 行为保持原有合同。
- 精确依赖官方 xcsc 1.0.3，Git 修订 `5641a33e991209eecdbbc91cffaa3be545875757`，同步 Cargo.lock 与产品能力清单；写入端随同一依赖更新使用 gate。
- 软件发行号更新为 1.0.3；既有业务协议、持久状态身份与 FFI ABI 不随软件补丁号改变。

## 升级提示

升级后先启动新版服务，再查询日志，让新版写入端建立 reader gate。新版读取端会拒绝尚未建立 gate 的旧日志目录；已建立 gate 的目录不能交给旧版写入端重新打开，因此不要将旧版服务直接回滚到该目录。

## 验证边界

本地检查与公共库原生回归测试不替代本产品最终提交的完整 CI、原生平台构建、签名和设备验收。正式资产以该版本标签对应的发布工作流结果为准。
