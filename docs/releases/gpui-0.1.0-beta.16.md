# XSCC GPUI 0.1.0-beta.16

修复低延迟 TCP 会话在短时发送积压时触发“Reset by the peer”的问题。该问题已在 Windows 本机会话复现：原逻辑把任一发送队列瞬时满当成永久故障，旧视频迁移超过两个包也会直接关闭连接。

视频继续使用有界队列。发生缺帧后，该屏幕等待新的关键帧，避免把缺少参考帧的后续画面继续送去解码；显示切换消息保持顺序。恢复请求依据实际写入进展限频，慢观看端不会阻塞其他观看端。音频积压淘汰旧音频；普通可靠控制消息采用有限入队等待，终止消息保留立即失败关闭与实际发送完成的约束。

保留 beta.15 的暖色底、青绿色主题及前面的采集、绑定恢复优化。服务端页面样式不变。本次不放宽授权、帧大小或队列上限。

多平台构建、实际安装与性能各自独立验证；回归测试不代表已经达到稳定 60 FPS 或完成安卓手机帧率验收。Windows/macOS 应用仍是未签名预览，iOS IPA 需要自行签名，Android 沿用既有预览签名。
