- Android可见输入字段接入真实原生EditText的系统长按菜单、选择手柄、复制、剪切和粘贴，删除原先下方操作行。键盘避让和样式更新保持当前输入会话；隐藏的远程键盘继续使用原路径，密码继续遮罩。
- iOS接入UITextInteraction及标准编辑动作，在首次触摸字段时提前准备焦点；正常粘贴、选择及全选使用系统交互，密码复制/剪切遵循secure默认保护。模拟器门禁会实际执行现有UIKit原生协议测试，不能以仅编译替代。
- 移动端顶部按钮视觉高度32px、点击范围44px；解绑使用稳定按钮和就近确认，进度、结果与错误在菜单下可见。本地实例信息开合不再被网络操作锁住。
- 移动端会话最外层和侧边工具栏空白区改为纯黑，覆盖横屏左右安全区；管理页、按钮和设置面板保留暖白青绿配色。
- 重新启用已有虚拟显示器时，按此前活动屏幕集合识别新活动屏，避免留在60Hz物理屏。 驱动重新枚举使旧显示名称失效时，优先选择仍可捕获的虚拟屏。
- Mtt虚拟屏目标信号明确设置IDD刷新率分频值为1，与固定驱动保持一致；模式确认读取目标信号及分频计算出的实际桌面率，不再仅相信路径标称Hz。实际60Hz不能再被当作请求120Hz已成功。
- Windows原生回归显式运行120/240Hz目标信号测试；Android版本提升为code22，保留原包名和签名，可覆盖安装。

Windows、Linux、macOS、Android和iOS发布候选均须来自本版同一提交，完成对应完整原生构建与校验。Windows/macOS为未签名预览，iOS IPA需自行签名。
