# XSCC GPUI 0.1.0-beta.7

本版根据 beta.6 手机测试反馈，将鼠标三键改为画面内悬浮按键，并修复鼠标指针模式的旧坐标重锚问题；同时保留前轮横屏会话、桌面布局、光标和连接热路径改进。

- 移动端可切换“触控”和“鼠标”。触控直接操作画面；鼠标模式使用相对滑动移动指针，轻点左键、双指轻点右键、双指滑动滚动，并可展开左键、中键和右键。中键发送真实鼠标中键按下/释放，滚动继续使用双指手势。切换模式、显示器、权限或离开会话时释放正在按下的输入。
- 操作、键盘、显示和退出集中在可收起的侧边工具栏。左、中、右键以半透明圆形按钮悬浮在远程画面上，不再占用独立底部区域，也不为三键缩小视频。设置面板与键盘仍使用独立区域，远程画面保持比例缩放；窄屏设置面板改为下方布局。
- 进入移动会话时请求横屏和沉浸呈现，退出或进入后台时恢复原方向与系统栏。Android 支持传感器左右横屏和滑动临时显示系统栏；系统栏隐藏不包含软键盘。iOS/iPadOS 使用公开的窗口场景方向请求和控制器显示策略；多窗口模式可能拒绝方向变更，布局继续使用实际窗口大小和安全区域。
- 移动端按远程光标形状、热点及画面缩放绘制指针；鼠标模式持续使用同一份本地位置进行绘制和点击，仅在新显示器、尺寸首帧或实际切换模式时初始化位置。迟到的远端坐标不再导致松手跳回、下一次触摸重新锚到旧点。缺少光标形状时显示箭头，形状更新不复制每个视频帧。
- 桌面会话默认将空间用于远程画面，设备侧栏可展开；屏幕、目标帧率、统计、全屏和断开集中在画面外的工具栏。统计支持关闭、简洁和详细，区分接收、解码与 UI 提交帧率。目标帧率支持 30、60、90、120，实际结果取决于采集、网络、解码和显示能力。
- 视频更新复用独立缓存菜单。后台管理轮询不再禁用操作按钮，相同状态不重复刷新界面，晚到的旧状态不能覆盖新操作结果。绑定失败保留密码，绑定成功后才清除；私网 HTTP 管理地址继续可用。
- 多个候选地址共享 18 秒连接预算；未响应时每隔 250 毫秒启动下一尝试，明确失败时立即继续。完成加密握手、双向管理证明及最新授权检查的连接才能胜出，其余尝试释放连接。
- 质量遥测使用独立最新值槽位，避免挤掉错误与权限事件；切换显示器时清除旧指标。移动输入在锁内检查最新授权，避免复制整个设备策略和密钥；图像上传按显示帧合并。
- 桌面按钮、设备卡片和输入框支持键盘焦点顺序；远程画面取得焦点后，Tab 和常用组合键仍发送到远端。

Windows、Linux、macOS 和 Android 版本名统一为 `0.1.0-beta.7`。Android 使用 versionCode 7，沿用固定预览签名，可覆盖安装此前使用同一签名的预览版。移动端只提供控制端。Windows 和 macOS 产物仍未签名。

升级 Windows 被控端时，关闭界面，运行原卸载程序后再运行新 setup；保留受管安装身份、绑定和配置。文件归档不能替代系统服务安装。控制端便携包替换前关闭旧程序，并保留原配置目录。

本版源码以最终发布 tag 绑定的提交为准。发布收集器要求五个平台候选来自同一源码提交并全部成功，核对来源、制品摘要及包内构建记录；发布来源见 `release-provenance.json`。发布说明本身不表示候选构建已经通过。

桌面行为回归、移动输入与布局回归、Android 输入桥 JVM 回归和 UIKit API 类型检查用于各自覆盖范围的验证，不能替代完整原生构建或真机验收。beta.6 的手机反馈用于本轮修复定位；beta.7 的悬浮三键和指针重锚修复尚未获得用户真机验收。触控、旋转、沉浸、软键盘和后台恢复仍需对应物理设备确认，也未给出端到端帧率、显示延迟或功耗承诺。

光标形状缓存最多保留 128 个形状、16MiB 像素；淘汰后仅收到形状编号时，当前协议不会补发像素，桌面恢复本机指针，移动端使用箭头。现有认证与授权边界保持适用。YUV/GPU 零拷贝解码呈现、交换链和采集编码流水线不属于本版实现范围。
