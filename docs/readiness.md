# 原生运行验收

应用源码已独立归并在 xscc，跨平台管理生命周期、实例绑定界面、授权列表、地址上报、持久回执和会话证明已接入。默认构建启用 `managed`。实现细节与必要变更路径见 [原生管理接入](native-management.md)。

协议、恢复、文件权限、排他锁、去重回执和证明测试与完整应用测试分别执行。诊断中的 ready 只代表实际原生监听器已经运行并能提供真实版本，不代表屏幕捕获、硬件编码或端到端串流已经通过验收。

发布前需要物理设备验证：

1. Windows 主控和被控分别绑定实例，通过服务端配置关系后连接；核对音视频、输入和重连。
2. 撤销关系、轮换凭据、解绑、断开管理服务，验证新连接被拒绝和既有连接关闭；恢复后仅允许当前关系。
3. 验证普通直连在未绑定时正常，首次绑定后原有非受管会话关闭；目录损坏或凭据失效时拒绝连接。
4. 验证用户/服务切换、睡眠恢复、响应丢失后的原身份恢复、断线执行与丢失回执重放。
5. 验证自动 IP 上报、域名与自定义端口、多地址、IPv6，以及监听关闭后的地址撤回。
6. 验证 Wayland 与 macOS 26 Apple Silicon 对应原生权限、正常串流和控制端选项。
7. 在 iOS 26/iPadOS 26 与 Android arm64 上验证控制端绑定、键鼠/触控、音视频、前后台切换及恢复后的租约更新；验证移动端不能绑定为被控实例。

不接管旧版服务或旧状态目录，不自动迁移旧任务与凭据。媒体链路性能调整仍以真实串流测量为前提。
