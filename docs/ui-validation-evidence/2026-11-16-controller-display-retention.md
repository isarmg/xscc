## 待实机复验：Android UI 上传

- 旧包真机采样时，面板和 Surface 均为 120Hz；持续变化的原生 120Hz 源接收/解码约 115–120 FPS，但 UI 提交约 79–97 FPS。Mailbox 对照没有改善，已恢复 FIFO。
- 经用户授权的 simpleperf 15 秒采样无丢样本；主线程 1,905 个样本中，51.37% 的调用链落在 atlas 更新至 `Queue::write_texture`，26.45% 涉及 GPU 分配，24.92% 为 memcpy 自身开销。这是旧上传路径的证据，不是新包性能结论。
- 新实现只对 Android 大图 atlas 替换复用 StagingBelt，按 GPU 完成后再复用缓冲区，非阻塞回收；支持有行填充的自定义宽度。超出设备映射缓冲区限制时保留直接上传路径。小图、字形及非 Android 路径不变。两项布局/溢出回归通过。
- Android 最终源码 `ba20d5dd429ba47dc01063d0ad14703438f6b33f`，[构建 43849164224](https://github.com/isarmg/xscc/actions/runs/43849164224)，版本 `4.0.0-beta.8` / `40008`；管理 APK 的 SHA-256 为 `6b49d6388c3634eb6517463f5eed24e840f9c249c92cdc98d8516f3dd065e3a3`，本地签名校验通过且签名身份与已装包一致。
- 手机 USB 已断开，用户选择先完成 Windows 更新；最终 APK 尚未覆盖安装，UI 帧率提升未通过实机验收。不得把构建成功、120Hz 请求或上述原生模式读数当作 Android 高刷问题已解决。
